# Корпус русского рассказа: база персонажей

Интерактивная база персонажей и их взаимодействий для 1000 русских рассказов XX века (1901–2000). Для каждого рассказа извлечены персонажи и связи между ними, результат показан в виде графа.

**Сайт:** https://vivi0424.github.io/Russian_short_stories_1000/

## Корпус в цифрах

| | |
|---|---|
| Рассказов | 1 000 |
| Период | 1901–2000 |
| Персонажей | 11 813 |
| Взаимодействий (рёбер графа) | 16 373 |
| Типов взаимодействий | 7 |

## Как это сделано

1. **Извлечение.** Персонажи, их имена и варианты именования (алиасы) и взаимодействия извлекались из текстов рассказов с помощью большой языковой модели (LLM).
2. **Типология взаимодействий.** Чтобы связи между персонажами можно было сравнивать и визуализировать, была разработана собственная типология из 7 типов (см. ниже).
3. **Валидация.** 100 рассказов проверены экспертами вручную, точность извлечения составила 85%.
4. **Визуализация.** Для каждого рассказа строится интерактивный граф: узлы — персонажи, рёбра — взаимодействия с цитатами-подтверждениями из текста.

## Типы взаимодействий

| Тип | Значение | Количество |
|---|---|---|
| `speech` | речевое взаимодействие | 7 834 |
| `co_presence_joint_action` | совместное присутствие, совместное действие | 4 845 |
| `conflict` | конфликт | 4 522 |
| `request` | просьба, приказ | 4 074 |
| `help_support` | помощь, поддержка | 3 637 |
| `kinship` | родство | 2 995 |
| `transfer` | передача предметов | 2 435 |

Одно ребро может иметь несколько типов.

## Структура данных

```
├── index.html          # интерфейс сайта
├── app.js              # загрузка данных и отрисовка графа (vis-network)
├── style.css
├── stories_index.json  # список рассказов: id, автор, название, год, путь к файлу
└── data/               # по одному JSON-файлу на рассказ (1000 файлов)
```
